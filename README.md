# Portfolio React

A personal portfolio built with React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern Tech Stack**: React 19, Vite, TypeScript.
- **Styling**: Tailwind CSS for rapid and responsive design.
- **Animations**: Framer Motion for smooth transitions and interactions.
- **Project Structure**: Organized components, hooks, and pages.

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/xiskg/portfolio-react.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📦 Build

To create a production-ready build:
```bash
npm run build
```
